# ClipDock Browser Extension

This folder is a complete Chromium Manifest V3 extension for ClipDock.

## Install In Chrome, Edge, Or Brave

1. Start ClipDock on Windows.
2. Open the browser's extension management page:
   - Edge: `edge://extensions`
   - Chrome: `chrome://extensions`
   - Brave: `brave://extensions`
3. Enable **Developer mode**.
4. Choose **Load unpacked**.
5. Select this `Extension` folder.

## Pair With ClipDock

1. In the ClipDock desktop app, open **Settings**.
2. Under **Browser integration**, select **Copy** beside the pairing token.
3. Open the ClipDock extension settings.
4. Paste the token and select **Save and test**.

The token is stored in the current browser profile. It is sent only to the ClipDock service running on the local device.

## Use

Open a YouTube watch page or Short. Use the small **Download** action beside YouTube's normal actions, or open ClipDock from the browser toolbar. Available formats and estimated sizes come from the desktop app; the extension does not download media itself.
